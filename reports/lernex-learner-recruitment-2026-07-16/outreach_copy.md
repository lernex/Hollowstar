# Lernex cohort outreach copy

## Core positioning

Lernex turns a learner's real class material, notes, questions, exam pressure,
or a topic from scratch into one adaptive learning path. It carries context
forward across explanations, practice, mistakes, saved lessons, flashcards,
video, test prep, and review instead of resetting to a blank chat each session.
